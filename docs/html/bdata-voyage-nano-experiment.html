Voyage-4-nano scores below chance on B-data accept/decline

Frozen voyage-4-nano cosine on the locked production dump data/B-data.json, same seeker-disjoint holdout as the TF-IDF B-data run — compared against the earlier nano baseline on the old 200-pair seed set.

Holdout pair AUC 0.469 — below chance

What was tested

  • Isolated package bdata_voyage_nano/ — does not edit baselines/voyage_nano/ or bdata_tfidf/.
  • Frozen Voyage-4-nano (Modal A10G), max_length 8192, truncate_dim 1024. No training; train split unused.
  • PENDING dropped; ACCEPT vs REJECT only. Matched split with TF-IDF (split_hash 0f050493daf9…).
  • Holdout: 5,585 pairs / 2,089 seekers (4,885 ACCEPT / 700 REJECT).

On B-data, REJECT pairs score slightly higher cosine than ACCEPT (gap −0.005). Hard negatives invert badly (AUC 0.36). The same frozen model that was weakly above chance on the old seed set is below chance here — and loses to plain TF-IDF on the identical holdout.

How to read this

  • Nano’s modest seed-set signal (≈0.56–0.58) does not transfer to this larger, yes-skewed production dump.
  • B-data accept/decline is not a frozen-embedding cosine problem for voyage-4-nano — same story as TF-IDF, but worse.
  • Hard-neg inversion (looks related → still declined) is the live production population; nano scores it furthest below chance.
  • Within-seeker ranking at 0.50 means the model also fails when seeker identity is held fixed.
