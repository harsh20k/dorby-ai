What the model actually sees each step

Both towers are the same model with the same weights, called through two different prompt prefixes — one for the seeker's ask, one for a candidate profile. Training pushes the accepted candidate's vector toward the seeker's and everything else away.

This is the lever that works

Read against Arm C, the baseline corner

Against the baseline corner (Arm C), raising micro-batch from 2 to 6 with no other change gained +0.042 MRR and +0.052 recall@1 — both above the measured noise floor. This arm is the best configuration tested, beating the earlier bigbatch run on every metric except recall@1 (a tie), while using simpler data (one negative per row, no duplicates).

But note what a larger sample showed later: on all 200 real pairs this model's advantage over frozen nano is +0.0001 pair AUC and +0.0000 recall@1 — zero. Only hard-negative AUC (+0.051) and recall@10 (+0.050) survive. See the 200-pair evaluation.
