Basic checks run on the batch itself, before spending any GPU budget.

Candidate-only and seeker-identity leakage were both higher here than in rrf_002 — the batch top1_ctrl traces back to. This run's pair AUC (0.6081) is the best of any fine-tune in the project. The training-row format (candidates compared within one query, not against the global base rate) plausibly absorbs some of that leakage, but this experiment does not prove how much — the leakage measurement and the pair-AUC gain point the same direction, which is reason for caution, not celebration.
