LLM judge vs. embedding baselines n = 69 (holdout)

Can an LLM predict accept/decline from two full profiles alone, with no searchQuery — the one thing every embedding baseline below gets? Every chart and table on this page is scored on the frozen 69-pair real holdout split (data/synthetic/seed_split.json's eval_pair_ids), not the full 200-pair real dataset — this is the smaller, harder, user-disjoint slice used for the project's one-time final comparisons, matching docs/baseline-results-holdout.md. 200-pair numbers exist per-experiment in docs/llm-judge-experiment.md and docs/llm-judge-focused-prompt-experiment.md but are not plotted here, to keep every row on this page the same population.

Hard-negative AUC vs. easy-negative AUC n = 69 (holdout)
