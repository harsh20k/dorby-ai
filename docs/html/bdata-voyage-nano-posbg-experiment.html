Narrower packing is barely above chance; retrieval fails

Frozen voyage-4-nano cosine on locked data/B-data.json, narrower packing (seeker = lookingFor + query, candidate = positioning + background), every resolved pair, plus retrieval against the unique-candidate pool.

Pair AUC 0.5185 — near chance; MRR 0.032

What was tested

  • Isolated package bdata_voyage_nano_posbg/ — does not edit bdata_voyage_nano/, bdata_tfidf/, or baselines/voyage_nano/.
  • No train/holdout split. PENDING dropped; ACCEPT vs REJECT on all 18,304 resolved pairs (15,821 / 2,483) from 6,962 seekers.
  • Candidate ids: real Boardy ids where present, else cmb + first 25 hex of identityKey. 3,104 Boardy-id collisions across positioning hashes were minted. Map written only under this experiment’s artifacts.
  • Retrieval: each ACCEPT query ranked against 21,168 unique match-role people (2 ACCEPT pairs skipped, candidate not in corpus).
  • Modal A10G ap-UqnhokCeY5vqmIz9QEEYEC stopped 18:40 ADT, ~29 min, clean completion.
