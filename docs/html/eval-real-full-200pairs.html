Does the fine-tune hold up on all 200 real pairs?

Every two-tower number so far was measured on 69 pairs. Re-measured on all 200, most of the advantage disappears — but one metric survives, and gets stronger.

← Arm A, the model tested here ← Ablation verdict

Why 200 pairs is a fair test of this model

Arm A trained on 583 rows built entirely from synthetic profiles. It saw zero real pairs and zero real profiles — confirmed two ways: the profile generator ran on the v3+ prompt, which no longer seeds generation with real profile text, and none of the 297 real contact ids appears anywhere in the training batch.

So the 131 "train" pairs are just as out-of-sample for this model as the 69 holdout pairs. That is not true of models that trained on real pairs, so the eval refuses any adapter whose provenance doesn't prove an all-synthetic training source.

Sanity check before reading anything new

Frozen nano's holdout row came back 0.5793 / 0.5707 / 0.4610 / 0.2759 / 0.7586 — digit-for-digit identical to the existing baseline artifact, which was produced by a completely different encoding path. Arm A's rows reproduce the published ablation table too. The pipeline is measuring the same thing as everything before it.

What this changes

The headline result does not generalise

On the 131 real pairs outside the holdout, pair AUC is −0.003 and recall@1 sits inside noise. Pooled over all 200, pair AUC is +0.007 against a ±0.014 noise floor. The "+0.026 pair AUC, +3.5 queries at rank 1" reported from the holdout is a property of that 69-pair sample, not of the model.

And the holdout is an easier population

Frozen nano — no fine-tuning involved at all — scores 0.5793 on the holdout versus 0.5507 on the train split. Any single-number comparison against the holdout inherits that bias.

What genuinely survives

Hard-negative AUC improves on every population, and by more on the larger ones: +0.040 on the holdout, +0.059 across all 200, +0.072 on the train split. Each clears its own noise band, and the effect growing with sample size is the opposite of what a sampling artefact does. Frozen nano is below chance on the train split's hard negatives (0.4690); the adapter lifts it to 0.5411.

This is the metric that matters most. In production there is no easy-negative population — every real negative is an intro the system already recommended and a human still declined. Recall@10 holds up everywhere too (+0.045 to +0.078), while recall@1 does not: the adapter is better at getting the right person into a shortlist, not at putting them first.

Read these numbers with two limits in mind

  • Retrieval metrics are not comparable between the three tables. Each subset ranks against its own candidate pool — 178, 120 and 65 — and a bigger pool is strictly harder. A lower MRR on the 200-pair table means the pool grew, not that the model got worse. Pair AUC has no pool dependence and is comparable throughout.
  • The noise estimate is two runs, not a confidence interval. It bounds run-to-run variation, not sampling error on the pairs themselves.
