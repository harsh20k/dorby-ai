Qwen3-Embedding-8B Sets New Project Records

twotower_qwen_bigbatch found that fine-tuning Qwen3-Embedding-8B, unlike nano, produces gains that actually generalize to real pairs. This experiment points that same recipe at voyage_gemini_ctrl_001's newer, bigger, leakier batch — and sets a new project-wide best on both pair AUC and hard-negative AUC, on plain full-profile text, beating every embedding model and the LLM judge measured in this project so far.

This matches twotower_qwen_bigbatch's own finding that Qwen's holdout-vs-real gap runs roughly 4x wider than nano's — exactly why the strong holdout numbers (0.74 AUC, 0.79 hard-neg) were never reported as the answer on their own. Same leakage caveat as voyage_gemini_ctrl_001 also applies here: this batch is an unreviewed pilot, measurably leakier than prior sources on pre-training checks — the record above deserves caution, not a victory lap.
